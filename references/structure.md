# 目录结构与命名规范详解

## 一、目录结构

### 收纳区 `1-收纳/`（PARA 思想：按「行动性」分类，不按「主题」分类）

| 子目录 | 用途 | 何时进入 |
|--------|------|----------|
| `1-收件箱/` | 快速捕获的想法、碎片，未分类 | 随手记、临时记录 |
| `2-项目/` | 有明确目标、有起止时间的活跃项目 | 进行中的学习/竞赛/项目 |
| `3-领域/` | 长期持续的责任领域（个人成长、学业、实验室等） | 长期维护的主题 |
| `4-归档/` | 已完成或暂停的项目 | 项目结束、超期无活动 |
| `模板/` | 笔记模板（tpl-note、tpl-weekly-review 等） | 新建笔记时套用 |
| `附件/` | 手册 PDF、图片等非 .md 文件 | 引用的外部资料 |

### 学习区（知识沉淀的核心）

| 目录 | 定位 | 特点 |
|------|------|------|
| `2-学习笔记/` | **主角**，问题解决笔记 | 记「这次的事件」：时间、场景、踩坑、解决步骤，自包含，阅读单篇即可解决对应问题 |
| `3-主题笔记/` | **配角**，通用知识 | 记「通用的概念」：定义→原理→应用→对比，脱离当前项目仍成立，被多篇学习笔记共享 |

### 其它

| 目录/文件 | 用途 |
|-----------|------|
| `4-周复盘/` | 每周总结、反思、下周重点 |
| `0-首页.md` | 库的总入口，用 Dataview 汇总待办/最近笔记 |
| `问题索引.md` | 「遇到问题先查这里」的速查表，解决后补进索引 |
| `README.md` | 库说明文档，介绍怎么用 |

## 二、命名规范

### 三种命名，不可混用

1. **顶级目录 / 顶级文件**：`数字-名字`（连字符 `-`），用于排序。
   - 例：`0-首页.md`、`1-收纳`、`2-学习笔记`、`3-主题笔记`、`4-周复盘`
   - 目的：让条目按数字顺序排列，首页 `0-` 永远在最前。

2. **学习笔记**：`序号. 题目`（点 + 空格），序号按创建时间递增。
   - 例：`1. 知识库搭建与ESP32学习启动.md`
   - H1 标题与文件名一致（去掉序号），不含日期；日期放 frontmatter 的 `created` 字段。

3. **主题笔记**：`题目`（纯题目名，**严禁**加时间戳）。
   - 例：`[[单片机GPIO原理]]` → 文件名必须是 `单片机GPIO原理.md`
   - ⚠️ 带时间戳（如 `2026-08-05_0105_单片机GPIO原理.md`）= 链接断裂 → Obsidian 找不到 → 自动建空白文件。

### wikilink 核心原理

`[[wikilink]]` 按**文件名**在整个 Vault 中匹配，与文件所在目录无关。链接成功的唯一要求是：**文件名全局唯一，且与 `[[链接名]]` 完全一致**。

> 推论：主题笔记放 Vault 根目录还是 `3-主题笔记/` 子目录，不影响链接；影响链接的只有「文件名是否一致、是否全局唯一」。

## 三、首页设置

首页 `0-首页.md` 是库的总入口，常用两个机制：

1. **Dataview 查询**：首页内嵌 `dataview` 查询块，自动汇总待办、最近学习笔记、主题笔记成熟度：
   ```dataview
   TASK
   WHERE !completed
   SORT file.name ASC
   ```
2. **文件列表置顶**：Obsidian 文件浏览器默认「文件夹优先」（所有文件夹排在所有文件前），`0-首页.md` 作为文件无法排到文件夹前。解决方式二选一：
   - 用 Pinit 插件把首页固定到文件列表顶部；
   - 或装 Homepage 插件，让 Obsidian 打开时直接显示首页（更推荐，打开即首页）。

## 四、笔记迁移流程（旧结构 → 新结构）

当知识库从旧结构迁移到本结构时，按此顺序操作，避免断链：

1. **先规划映射**：列出旧笔记 → 新位置的对应表（哪篇进学习笔记、哪篇进主题笔记、哪篇归档）。
2. **移动 + 改名**：按命名规范移动文件并改序号/纯名。
3. **同步更新 wikilink**：改名后，所有引用它的 `[[旧名]]` 都要改成 `[[新名]]`。批量替换后**必须验证**。
4. **验证零断链**：用 Obsidian CLI 的 `obsidian unresolved` 检查，应为空；`obsidian orphans` 列出的孤儿文件应为「首页、模板、附件、README」等本就不该被链接的文件。
5. **清理重复待办**：用 `obsidian tasks todo` 检查是否有同一待办在多个笔记重复出现，合并保留语义最合适的一处。
6. **清理空 checkbox**：模板里的空 `- [ ]` 占位符会被 Dataview 当成空任务抓进首页，应删除或用 HTML 注释（`<!-- -->`）替代提示。
