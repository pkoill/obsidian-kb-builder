# 知识库操作流程

创建学习笔记、每周复盘、快速捕获、搜索四个操作的具体做法。健康检查的完整流程见 `health-check.md`。

## 一、创建学习笔记（问题驱动，先搜索后新建/并入）

1. **先搜索**：用 `obsidian search query="关键词"` 检查知识库是否已有同主题笔记。
2. **判断并入 or 新建**：已有同主题 → 更新现有笔记（补章节、改参数、加修订），不新建；没有 → 才新建。
3. **新建**：
   - 路径 `2-学习笔记/`，命名 `序号. 题目`（序号按创建时间递增，日期放 frontmatter `created`）；
   - frontmatter 必备 `created` + `tags` + `status`；
   - 正文按 `writing.md` 的结构写，结尾栏目顺序固定。
4. **链接必填**：写 `[[wikilink]]` 时一并创建目标笔记并填内容，禁止空占位链接。

## 二、每周复盘

1. 扫描 `2-学习笔记/` 本周笔记，找出可提炼的知识点。
2. 对每个知识点判断：已有主题笔记 → 并入更新；新主题 → 按「新建 vs 并入」新建。
3. 检查并修正被本周实践推翻的旧认知（在原笔记改正文，不堆 `_v2`）。
4. 汇总本周进展、决策、沉淀、下周重点，写成周复盘笔记，放 `4-周复盘/`（命名 `W周数-日期`）。

## 三、快速捕获

把零散想法写入 `1-收纳/1-收件箱/`，暂不分类；后续整理时再归入学习笔记或主题笔记。

## 四、搜索知识库

- 优先用 Obsidian CLI 走索引：`obsidian search query="关键词"`；
- 全文/带上下文检索：`obsidian search:context query="关键词"`；
- 反向链接、属性、任务等更多命令见 `cli.md`。
