# 资源选择规则详解

笔记末尾的资源链接怎么选、怎么摆、怎么写。
针对学习资料，主动笔记，不包括计划笔记，计划笔记的规则详见Skill.md
## 一、结构分两区

- `## 参考资源`（前面）：用于快速回忆，**2~3 条** 针对学习资料，主动笔记，不包括计划笔记，计划笔记的规则详见Skill.md
- `## 实操建议`（最后）：**学习笔记 / 主题笔记**放资料链接（视频 / 中文资源 / 英文资源，1~3 条，每类最多 1 条）；**计划类笔记**放「具体怎么做」的文字（不填资源链接）,计划类笔记必须要有实操建议。

## 二、参考资源的 4 个层次（条数 = 覆盖必要层次的最少条数）

| 层次 | 定位 | 例子 |
|------|------|------|
| ① 直觉 | 短视频（10 分钟左右） |推荐 B站教程 ，但不止于B站，要求中文资源视频|
| ② 快速权威 | 中文资源（博客、网站等） | 优质博客、官方中文文档 |
| ③ 系统 | 中文教材（书） | 《动手学深度学习》 |
| ④ 深度权威 | 英文文档（最权威，可占推荐位，标注「英文」） | 官方手册、原论文 |

> 优先推荐中文教材（方便阅读），再补充英文权威手册（深入学习）。

## 三、引用格式（禁止只丢裸链接，每条必须含）

1. **书籍**：`《书名》- 作者名 - 第 X 章-章节名`
2. **芯片手册**：`芯片型号 + 文档编号 + 章节`
3. **应用笔记**：`厂商 + ANxxxx + 标题`
4. **在线资源**：`文章标题 + 作者/机构 + 链接`（作为补充，不替代书籍）
5. **论文**：学习计划涉及重要/经典论文时，在计划开头加 `## 📄 核心论文` 章节（引用块呈现：论文标题 + 作者/机构/年份/会议 + arXiv 链接 + 页数 + 一句话贡献），并把论文列入对应步骤的学习资源。**触发条件**：用户是研究生或做科研的本科生必带；用户未透露身份但计划涉及重要论文或前沿/热门方向时也带；其余不带。
6. **链接顺序**：多条参考资源按 4 层次从浅到深按顺序排列——① 短视频（10 分钟左右，建议B站链接） → ② 中文资源（博客、网站等中文资源）→ ③ 中文教材 → ④ 英文文档。注意，这只是根据提供的资料的种类来排序的，不是说只能放 4 个或者说必须放 4 个。建议中文资源放在英文资源之前。这条规则适用于所有类型的笔记。

## 四、搜索原则（最高原则）

- **广泛搜索**：不局限固定网站，用多种方式搜索——已有的搜索 skill、WebSearch、Agent 浏览器（如 Playwright MCP 等浏览器自动化工具）等等；
- **客观搜索**，忠于笔记主题思想，以「解决问题 + 提高认知 + 沉淀知识」为唯一目的；
- **按主题选取来源**：从广泛搜索的结果中，选取最合适当前学习内容和主题的资源链接呈现给用户，而非局限于固定网站清单；
- **去重**：同一主题/内容的多个链接只保留质量最高的一个，删掉冗余——多个资源讲同一件事时，宁可少而精，不重复堆砌；
- **中文与免费并重**：在质量合格的前提下，中文来源与免费来源同等重要，避免读者打开付费墙,避免推荐YouTube等国外翻墙网站,要求国内友好使用网站；
- **不预设**对任何来源（CSDN / 博客园 / 知乎 / B站 / GitHub / 官方文档 / 中文 / 英文等等）的偏好或偏见，内容质量和适合度决定取舍，避免推荐YouTube等国外翻墙网站,要求国内友好使用网站；
- CSDN 内容若质量合格即可采用，不因收费而排除；无 CSDN 来源亦无妨；
- GitHub 可用于推荐开源项目、学习资源、Skill 等链接。

## 五、格式约束

- 不用「必读/必看/必记」等主观夸大词；
- 视频条目不写「长视频/短视频」等泛化词，写具体时长（如「3分45秒」）；
- **视频时长控制**：推荐视频时控制时长——直觉定位（快速建立认知）控制在 10 分钟左右；深刻理解定位（系统学习）最好在 1 小时内。合集本身不算时长限制，但合集中的单集超过 1 小时也不推荐。尽量推荐时间短、能迅速理解的视频。
- 英文标注以「打开网站后用户看到中文还是英文」为准（中文转载不标英文，英文原文标「英文」）；
- CSDN 收费文章若引用：保留原链接，括号标「（CSDN文库）」，紧跟「网站名：链接」免费替代。

## 六、特例（学习计划/路线类笔记）

制定学习计划时免不了按学习路径引用大量学习资源，此时**打破** `参考资源` 的条数限制——每条步骤的学习资源**至少 4 条**、一条一行（不能只给两三个，同时避免推荐的资源有重复多余的内容）；第一条必须是视频（链接文本写视频标题，合集须标出具体集数）。

决策记录、学习总结等非计划/路线类笔记，不采用步骤驱动结构，亦不适用资源条数特例——仍按普通学习笔记的资源规则执行（参考资源3条 + 实操建议 1~3 条）。

## 七、实操建议的两种类型

`## 实操建议` 栏目因笔记类型不同，含义不同：

| 笔记类型 | 实操建议放什么 | 数量规则 |
|----------|----------------|----------|
| 学习笔记 / 主题笔记 | **资料链接**（视频 / 中文资源 / 英文资源） | 总数 1~3 条，每类最多 1 条，不要求每类都有 |
| 计划类笔记 | **具体怎么做**（文字，可执行动作） | 文字描述，不填资源链接 |

**学习笔记 / 主题笔记**——放资料链接，三种类型（中文资源含中文资料、中文网站等）：

- 视频（写具体时长，如「3分45秒」）
- 中文资源 (书籍/教材/网站/博客/视频...)
- 英文资源（标注「英文」）(书籍/教材/网站/博客/视频...)


数量规则：总数 1~3 条，**每类最多 1 条**（视频 ≤1、中文资源 ≤1、英文资源 ≤1），不要求每类都有；但实操建议存在于学习笔记和计划笔记中。

**计划类笔记**——放「具体怎么做」的文字（可执行动作，不是资源链接）。例如：

- ✅ 好：「先看 B 站视频建立整体印象，再逐词啃 6 个概念，最后用自检问题验证——答不出来就回看池化/上采样两条。」
- ❌ 差：「多加练习」「注意理解」
